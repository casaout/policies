# Engine Awesome subprocessors

*Last updated: November 20, 2026*

We use third party subprocessors, such as cloud computing providers and customer support software, to run Engine Awesome (the service).

The following is a list of personal data subprocessors we use. These subprocessors are all located in the United States:

* [Amazon Web Services](https://aws.amazon.com/compliance/gdpr-center/). Cloud services provider, for job queues and the infrastructure Laravel Cloud runs on.
* [Chaport](https://www.chaport.com). Live chat for customer support.
* [Cloudflare](https://www.cloudflare.com/gdpr/introduction/). Content delivery network, DDoS mitigation, and the Turnstile anti-bot service.
* [DigitalOcean](https://www.digitalocean.com/legal). Cloud services provider, for our workflow automation.
* [Laravel Cloud](https://cloud.laravel.com). Application hosting.
* [Laravel Nightwatch](https://nightwatch.laravel.com). Application monitoring.
* [Mixpanel](https://mixpanel.com/legal/privacy-policy/). Product analytics.
* [MongoDB Atlas](https://www.mongodb.com/legal/privacy). Database hosting.
* [Postmark](https://postmarkapp.com/security). Transactional email service.
* [Sentry](https://sentry.io/privacy/). Error monitoring, including recordings of browser sessions in which an error occurs, with text and form inputs masked.
* [Stripe](https://stripe.com/privacy). Payment processing services.
